# Code of Conduct

This project follows the Contributor Covenant Code of Conduct, version 2.1.

We commit to making participation welcoming and harassment-free, regardless of
experience level, identity, background, or device preference. Be kind, assume
good intent, and discuss the work rather than the person.

Unacceptable behavior includes harassment, discriminatory language, unwanted
sexual attention, publishing private information, threats, and sustained bad
faith disruption.

Report concerns privately through the maintainer's GitHub profile. Reports are
reviewed promptly and handled with discretion. The maintainer may remove,
edit, or reject contributions and participation that violate this code.

This policy is adapted from the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).
