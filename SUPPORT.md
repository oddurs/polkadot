# Support

Start with the [operations guide](docs/OPERATIONS.md) for installation,
customization, recovery, and timer behavior.

Use a GitHub issue for reproducible bugs or a concrete improvement proposal.
Include `polkadot doctor` output when it is relevant, after removing private
paths, tokens, and hostnames. Security reports belong in a private security
advisory, not an issue.

This is a personal setup published as a forkable base. The maintainer can help
with the supported macOS workflow, but cannot provide support for arbitrary
Linux, Windows, enterprise device-management, or private-service setups.
