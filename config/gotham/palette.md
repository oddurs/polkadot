# Gotham

Andrea Leopardi's palette, ported across the stack. Blue-black ground, muted
cyan text, and a set of "bright" slots that are deliberately *not* brighter —
Gotham spends 8–12 on darker blues used as UI shades rather than louder text.
That is why it stays calm at 2am, and why a naive port that brightens those
slots looks wrong.
